# Minimal SD assets

Copy the `eyes` and `boot` folders to the root of an existing FAT32 SD card without deleting other files. The pack includes only the home eye sheet and boot logo referenced by the firmware. Optional custom animations, widgets, music, recordings and photos are not bundled.

Origami confirmed ownership of its artwork and font on 21 October 2026. These original assets are included under the repository MIT license. External third-party artwork keeps its original notices.

Do not format an in-use card or copy credentials/device data into a release package. `asset-manifest.json` records the exact included bytes.
